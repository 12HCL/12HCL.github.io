Privacy policy

shiori-backup is used by its owner alone, to back up their own data to their own Google Drive.

  • It requests only the drive.file scope, so it can reach only the files it created itself, never anything else in the Drive.
  • It uploads backup archives, lists them and deletes old ones. It reads no other Google data.
  • The access token is stored only on the owner's own computer. Nothing is sent to any server other than Google's.
  • No data is collected, shared, sold or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
